# 오프비트

> 음악 큐레이션·플레이어 웹사이트 | 웹 디자인·퍼블리싱 / 프론트엔드 포트폴리오

## 프로젝트 소개
음악을 탐색하고 취향에 맞는 곡을 저장하거나 재생할 수 있는 사이트를 만들었습니다. 어두운 배경과 회전하는 커버 카드를 활용해 음악을 고르는 경험에 시각적 재미를 더했습니다.

## 사용 기술
React · Vite · JavaScript · CSS · React Router · Lucide React · HTML Audio · localStorage

## 주요 작업 내용

### 01. 추천 및 탐색
커버 이미지 10개를 회전형 레이아웃으로 구성하고 무드별 음악 탐색을 배치했습니다.

### 02. 검색 및 분류
곡명, 아티스트, 무드 검색과 장르 필터 기능을 연결했습니다.

### 03. 관심 곡
좋아하는 곡을 저장하고 다시 확인할 수 있도록 localStorage를 활용했습니다.

### 04. 플레이어
재생·일시정지·이전·다음·탐색 위치·볼륨·음소거 동작을 구현했습니다.

### 05. 재생목록
곡 추가와 삭제, 셔플과 한 곡 반복 기능을 구성했습니다.

### 06. 모바일 화면
작은 화면에서 플레이어를 접고 펼칠 수 있도록 레이아웃과 조작 영역을 조정했습니다.

## 작업하면서 익힌 내용
HTML audio와 React 상태를 연동하면서 재생 중인 곡, 진행 위치, 볼륨 등의 변경을 하나의 UI에 반영하는 방법을 익혔습니다. 카드 애니메이션과 인터랙션을 함께 다루는 경험도 쌓았습니다.

## 프로젝트 정리
음악 감상 기능과 시각적 인터랙션을 함께 구현하면서 사용성과 화면 분위기를 조율한 프로젝트입니다.
