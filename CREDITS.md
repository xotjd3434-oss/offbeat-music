# Credits

## 3D rotating cards

From Uiverse.io by ilkhoeri. User-provided HTML/CSS carousel adapted to React music-cover buttons. Rotation geometry, perspective and indexed transforms are based on the provided snippet.

Reference collection: https://uiverse.io/elements?search=music

Additional design references:
- https://uiverse.io/andrew-demchenk0/heavy-mule-52 — dark minimal player and playback controls.
- https://uiverse.io/Praashoo7/thin-sloth-31 — compact now-playing/list composition.
- https://uiverse.io/Manish-Tamang/honest-earwig-91 — progress, heart and volume controls.

The references above informed the interface; the application logic and player implementation are specific to this project.
